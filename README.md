# DriftGuard AI - Customer Churn Prediction

An AI-powered customer churn prediction project built using Machine Learning techniques.

## Features
- Customer churn prediction
- Data preprocessing
- SMOTE balancing
- Random Forest and XGBoost models
- Model evaluation

## Tech Stack
- Python
- Pandas
- NumPy
- Scikit-learn
- XGBoost

## Files

```bash
prediction.py
customer_churn.csv
requirements.txt
presentation.pptx
```

## Installation

```bash
pip install -r requirements.txt
```

## Run

```bash
python prediction.py
```
